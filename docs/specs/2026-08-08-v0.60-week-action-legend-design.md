# v0.60 Design — Week action legend

## Problem

v0.59 added deterministic effect hints via button metadata (`title` and
`aria-label`), but metadata still depends on hover/focus discovery. Athletes on
mobile do not reliably see hover hints.

## Scope

Add a visible, static legend row directly under Train week quick actions.

## Non-goals

- No action semantics changes.
- No server action or schema changes.
- No new quick actions.

## Behavior

`WeekAdjustmentSwitch` renders a compact legend:

`Ease -30% · Deload -50% · Boost +10% · Skip 0`

The existing per-button metadata hints remain in place.

## Rationale

- Guarantees effect visibility without hover.
- Keeps the existing compact control and deterministic behavior.
- Improves UI discoverability and mobile clarity with minimal surface change.

## Verification

- Week switch render test asserts legend text is present.
- Existing action labels/hidden-field tests continue to pass.
