# v0.59 Design — Week action effect hints

## Problem

Train week quick actions are compact and fast, but their deterministic effects
are implicit. Athletes must remember each action's multiplier, or trigger one to
learn what it does.

## Scope

Add static, deterministic effect hints to existing week action buttons in Train.

## Non-goals

- No backend or schema changes.
- No action semantics changes.
- No additional week actions.

## Behavior

In `WeekAdjustmentSwitch`, each action exposes its effect hint:

- Ease week -> `-30%`
- Deload week -> `-50%`
- Boost week -> `+10%`
- Skip week -> `set to 0`

Hints are attached as button metadata:

- `title="<label> (<hint>)"`
- `aria-label="<label> (<hint>)"`

## Rationale

- Keeps the compact control layout unchanged.
- Improves discoverability and accessibility without introducing new state.
- Mirrors existing deterministic action behavior exactly.

## Verification

- Week switch UI tests assert each hint renders in button metadata.
- Existing posting/hidden-field tests remain unchanged and pass.
