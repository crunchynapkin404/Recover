# v0.62 Sleep Debt Confidence and Guidance Design

## Summary

v0.62 strengthens sleep debt guidance by exposing data confidence directly with
the estimate, so users can distinguish robust guidance from sparse-window
estimates.

## Scope

- Extend `computeSleepDebt` result with confidence levels:
  - `none` when below minimum data threshold
  - `low` for 7-9 nights
  - `medium` for 10-12 nights
  - `high` for 13-14 nights
- Surface confidence text in the Sleep card when debt is available.
- Mark low-confidence debt deltas on Today with explicit "limited data" suffix.

## Non-goals

- No changes to sleep debt math itself.
- No notification or messaging automation.
- No schema migration.

## Risk controls

- Confidence derives only from counted nights in current debt window.
- Keep null behavior unchanged for insufficient data.
- Keep bedtime recommendation logic unchanged; confidence augments explanation.
