# v0.61 Adaptive Week Autopilot (MVP) Design

## Summary

v0.61 introduces a deterministic weekly autopilot adjustment based on previous
week adherence and completion signals. The MVP is intentionally bounded and
explainable.

## Scope

- Compute a weekly adherence score from:
  - adherence percentage (70% weight)
  - completion percentage (30% weight)
- Apply bounded autopilot adjustment against skeleton target:
  - high adherence: `+10%`
  - low adherence: `-15%`
  - neutral adherence: `0%`
- Emit explicit reason code prefixes in rationale text:
  - `AUTO_HIGH_ADHERENCE`
  - `AUTO_LOW_ADHERENCE`
  - `AUTO_NEUTRAL`
- Preserve existing safety logic for missed weeks and readiness suppression.

## Non-goals

- No new scheduler subsystem.
- No new background jobs.
- No new UI control surface in this MVP slice.

## Determinism rules

- Thresholds are fixed in code for this release.
- Rationale string generation is deterministic for identical inputs.
- Adjustment decisions are derived solely from persisted prior-week values.

## Risk controls

- Keep adjustment window bounded to avoid runaway load changes.
- Retain existing hard restart behavior for fully missed weeks.
- Keep readiness suppression intact as separate safety signal.
