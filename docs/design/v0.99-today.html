v0.99 design reference — Today (smallest surface)

Slice 0, Task 8. Today is the reference for the smallest surface: one route, five nav items, a handful of blocks. The redesign's organising idea is that Today leads with whatever moment the athlete is in — the route, the nav, the numbers and the blocks never change, only their order and emphasis do. This file shows all three states, in both themes, built from the type scale and ink ramp that shipped in src/app/globals.css. Every figure below is a field the app already computes (see the source captions on each block); values are representative sample data, not a live pull — this task does not touch the running app or its database.

Type scale — seven steps, 12px floor

--text-label is a hard floor: nothing in either mockup renders smaller. Today's own current UI already dips to 7.5px (the readiness ring's micro-label) and 9–11.5px in a dozen places — but because Today carries so little content, promoting everything to the floor costs nothing structurally. No cuts, no truncation, no drill-ins: just bigger numbers. (Train is the opposite case — see v0.99-train.html.)

Ink ramp — four steps, measured contrast

Ratios below are computed against each token's worst-case surface pairing in each theme (the same methodology tests/contrast-guard.test.ts enforces). --ink-muted is the floor for text — it clears AA (4.5:1) but only just. --hairline sits at ~3:1, which meets the separate non-text minimum (borders, icons, dividers) and is illegal on text in this system.

The rule above this line is --hairline — a divider, not a sentence. At ~3:1 it clears WCAG's non-text contrast minimum but fails the 4.5:1 text minimum in both themes, which is why every block below draws its dividers with it and never its captions.
