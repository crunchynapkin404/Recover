# v0.58 Implementation Plan — Week action freshness guardrails

## Goal

Prevent stale Train week quick-action posts from mutating non-open weeks after
rollover.

## Steps

1. Add failing action-layer test for stale week mismatch.
2. Add guard in `setWeekAdjustmentQuick`:
   - fetch open week
   - reject when submitted week does not equal open `skeletonWeek`
3. Verify stale submission writes nothing.
4. Keep all existing fresh-action behavior unchanged.
5. Update release metadata:
   - package version
   - changelog entry
   - roadmap release section
6. Run release gates:
   - focused tests
   - full tests
   - lint, typecheck, build

## Acceptance

- Stale mismatch returns `{ ok: false, error: "stale_week_adjustment" }`.
- No training-block target change occurs on stale mismatch.
- Existing quick actions still pass and retain current multipliers.
- No migrations or schema updates are introduced.
