# v0.51 - Plan styles and blocks - Implementation plan

## Objective

Ship deterministic selectable planning style (balanced and block_lite) while
preserving all existing readiness safety precedence and no-training-lost
accounting behavior.

## Non-negotiable constraints

1. Deterministic first: same input state and style must produce same output.
2. Safety first: style may not override readiness, legality, or adaptation
   precedence.
3. Backward compatible: missing style defaults to balanced with no behavioral
   drift.
4. Additive only: no migration unless a hard blocker is proven.
