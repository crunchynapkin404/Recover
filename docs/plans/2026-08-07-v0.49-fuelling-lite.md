# v0.49 - Fuelling Lite - Implementation Plan

## Objective

Ship deterministic, session-aware fuelling guidance as the first breadth
release, without changing plan-generation behavior.

## Non-negotiable constraints

1. Deterministic first: same inputs must produce same outputs.
2. Advisory only: fuelling must not mutate planned load or adaptation logic.
3. Confidence always visible.
4. Coach and UI must share one fuelling engine output.

## Work plan

## Task 1 - Add fuelling domain model and calculator

1. Add fuelling types and result model under src/lib/fuelling.
2. Implement pure calculator using duration and intensity bands.
3. Add confidence assignment logic based on input completeness.

Expected outputs:

- src/lib/fuelling/types.ts
- src/lib/fuelling/calculate.ts
- src/lib/fuelling/calculate.test.ts

## Task 2 - Bridge plan sessions to fuelling inputs

1. Add mapper from planned session shape to fuelling input.
2. Keep mapping isolated from adaptation logic.

Expected outputs:

- src/lib/fuelling/from-session.ts
- src/lib/fuelling/from-session.test.ts

## Task 3 - Add Train UI fuelling card

1. Create a mobile-first card component for before/during/after guidance.
2. Render confidence and assumption sentence in card footer.
3. Add explicit empty-state copy when input quality is low.

Expected outputs:

- src/components/train/fuelling-card.tsx
- src/components/train/fuelling-card.test.tsx
- wire into src/app/train/page.tsx

## Task 4 - Add coach parity path

1. Add or update fuelling coach tool to call shared calculator.
2. Ensure tool response includes confidence and assumptions.
3. Add tests to guarantee parity with UI result for same session.

Expected outputs:

- src/lib/tools/get-session-fuelling.ts (or equivalent)
- src/lib/tools/__tests__/session-fuelling.test.ts

## Task 5 - Docs and release notes

1. Update CHANGELOG with v0.49 section when implementation lands.
2. Update docs/ROADMAP.md with v0.49 release section.
3. Keep docs/specs/2026-08-05-ai-coaching-landscape.md breadth ladder in sync.

Expected outputs:

- CHANGELOG.md
- docs/ROADMAP.md
- docs/specs/2026-08-05-ai-coaching-landscape.md

## Verification gate

Run all before merge:

1. npm run lint
2. npm run typecheck
3. npm run test
4. npm run build

Targeted checks:

1. Fuelling output determinism tests pass.
2. Missing-input confidence downgrade is visible and tested.
3. Coach and UI parity test passes.
4. No diffs in week-plan or training-plan outputs from fuelling changes.

## Definition of done

1. Athlete sees fuelling guidance on planned sessions in Train.
2. Guidance includes before/during/after and confidence.
3. Coach can return the same guidance from same inputs.
4. Release is additive and does not change planning arithmetic.
