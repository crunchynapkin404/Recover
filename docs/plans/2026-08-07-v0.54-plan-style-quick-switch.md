# v0.54 Plan: Plan Style Quick Switch

Date: 2026-08-07
Scope: One focused implementation PR

## Objective

Deliver a Train-native quick switch for planning style (`balanced` / `block_lite`) using existing deterministic planning logic and existing style update pathways.

## In Scope

- Week UI style chip and switch interaction.
- Action wiring to existing style update pathway.
- Week refresh after update.
- Focused tests for UI and action path.

## Out of Scope

- Planning algorithm changes.
- New style options.
- Data-model migrations.
