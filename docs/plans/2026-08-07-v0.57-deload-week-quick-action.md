# v0.57 Implementation Plan — Deload week quick action

## Goal

Add a deterministic Train-native deload action that halves open-week target
load without changing planning algorithms or schema.

## Steps

1. Add failing tests for Train week-control labels/values and action count.
2. Add failing tests for action-layer deload behavior.
3. Extend week quick-action parsing in server actions:
   - accept `deload_week`
   - map reason to `train quick week deload`
4. Extend `update_training_plan` tool enum and execution:
   - accept `deload_week`
   - apply `newLoad *= 0.5`
5. Update tool registry expectation and frozen snapshot.
6. Update release metadata:
   - `package.json` version
   - `CHANGELOG.md`
   - `docs/ROADMAP.md`
7. Run release gates for touched surface:
   - focused tests first
   - lint, typecheck, build

## Acceptance

- Week adjustment control presents four actions, including Deload week.
- `setWeekAdjustmentQuick` returns `{ ok: true }` for valid deload requests.
- Deload writes rounded 50% target load with explicit action note.
- `update_training_plan` schema accepts `deload_week` and frozen tool test passes.
- Lint, typecheck, and build pass on the branch.
