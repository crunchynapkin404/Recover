# v0.61 Adaptive Week Autopilot (MVP) Plan

## Release goal

Ship deterministic weekly autopilot adjustment with explainable reason codes,
validated through focused week-plan tests and full release gates.

## In scope

- Effective load logic uses adherence + completion to choose high/low/neutral.
- Bounded adjustment window (`+10%`, `-15%`, or `0%`).
- Rollover path passes completion percentage to materialization input.
- Test updates proving deterministic outcomes and rationale codes.

## Out of scope

- Manual accept/reject controls.
- Messaging/notification automation.
- New database schema.

## Acceptance checks

- `src/lib/week-plan/materialize.test.ts` passes with new autopilot assertions.
- Week-plan integration tests remain green.
- Full release gate passes: lint, typecheck, tests, build.

## Verification commands

```bash
npm test -- src/lib/week-plan/materialize.test.ts
npm test -- tests/week-plans.test.ts src/lib/week-plan/service.test.ts src/app/plan/actions.test.ts
```
