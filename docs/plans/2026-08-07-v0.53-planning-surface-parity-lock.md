# v0.53 Planning Surface Parity Lock Implementation Plan

> **For agentic workers:** REQUIRED: Use the `subagent-driven-development` agent (recommended) or `executing-plans` agent to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Normalize and lock `effectiveStyle`, `effectiveSeasonMode`, and `reentryStage` parity across planning tools and the Train planning UI without changing planning behavior.

**Architecture:** Introduce one shared planning-surface resolver that computes effective planning state from plan constraints. Use that resolver everywhere planning state is read/written in tools and where Train UI derives constraints, then lock with targeted tests. Keep all week materialization and adaptation algorithms untouched.

**Tech Stack:** Next.js 16, TypeScript, Drizzle ORM, Zod, Vitest

---

## Objective

Create a single source of truth for planning-surface effective state so MCP tools and Plan UI report and apply identical `effectiveStyle`, `effectiveSeasonMode`, and `reentryStage` values.

## In Scope

- Add a shared planning-surface effective-state resolver.
- Refactor plan tools to consume shared resolver.
- Refactor Train planning surface to consume shared resolver for displayed/derived planning state.
- Add parity tests for tool outputs and plan UI derivation path.
- Preserve current behavior for style/season/re-entry outcomes.

## Out of Scope

- Any change to week planning/materialization/adaptation algorithms (`materializeWeek`, `adaptDay`, rollover load logic).
- Any change to plan generation periodization heuristics.
- Any schema migration.
- Any UI redesign beyond parity state wiring.

```ts
import { resolvePlanStyle } from "@/lib/plan-style/resolve";
import { normalizeSeasonState } from "@/lib/season-mode/resolve";

export interface PlanningSurfaceState {
  effectiveStyle: "balanced" | "block_lite";
  effectiveSeasonMode: "normal" | "off_season";
  reentryStage: "none" | "week_1" | "week_2";
}

export function resolvePlanningSurfaceState(
  constraints: Record<string, unknown> | null | undefined
): PlanningSurfaceState {
  const c = constraints ?? {};
  const season = normalizeSeasonState({
    seasonMode: c.seasonMode,
    reentryStage: c.reentryStage,
  });
  return {
    effectiveStyle: resolvePlanStyle(c.planStyle),
    effectiveSeasonMode: season.seasonMode,
    reentryStage: season.reentryStage,
  };
}
```
