# v0.59 Implementation Plan — Week action effect hints

## Goal

Make Train week quick-action outcomes explicit before submit by adding static
hint metadata to each action button.

## Steps

1. Add failing UI tests expecting per-action hint metadata.
2. Extend `WeekAdjustmentSwitch` action definitions with hint text.
3. Render `title` and `aria-label` as `<label> (<hint>)` on each button.
4. Run focused week-switch tests.
5. Update release metadata:
   - package version
   - changelog
   - roadmap section
6. Run release gates:
   - tests
   - lint
   - typecheck
   - build

## Acceptance

- Each week action renders its deterministic effect hint.
- Hints are available via `title` and `aria-label`.
- Existing week action behavior and posting semantics do not change.
- Release gates pass.
