# v0.52 - Off-season mode - Implementation plan

## Objective

Ship deterministic off-season maintenance mode with explicit staged re-entry,
without changing safety precedence.

## Task list

1. Add `seasonMode` / `reentryStage` type contract and resolver defaults.
2. Add deterministic workout shaping for off-season/re-entry.
3. Integrate shaping into `materializeWeek` before placement.
4. Add rollover progression helper for re-entry stage.
5. Extend planning tools for mode/state set/read parity.
6. Lock regressions with targeted tests and full verification gate.

## TDD checkpoints

1. Resolver tests fail then pass.
2. Off-season shaping tests fail then pass.
3. Materialize off-season tests fail then pass.
4. Service progression tests pass.
5. Tool schema and output contract tests pass.
